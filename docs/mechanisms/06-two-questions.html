Vörður · mechanism strip 06

One Call, Two Questions

A tool call looks like one decision, so people expect one verdict. It is really two unrelated questions asked of the same request: whether the action may happen, and whether the bytes it carries may leave. Passing one is not passing the other.

So who asks the second question

That depends on how Vörður is wired in, and it is the practical takeaway of the whole strip. As a library, you do. The threat model states it as assumption A-AS9: the application calls check_outbound on every outbound channel it can, including the content carried in tool-call arguments, and enforces the block. Nothing in the library can do that for a channel it was never shown.

Two arrangements take it off your hands, and one of them is off until you turn it on. prepare_tool_call runs the content checks over every string leaf of the argument tree, which is what the last panel showed, but only when the privacy vault is on, and Guard() constructs without one: called on a default guard it returns allowed=True with the reason privacy disabled, having scanned nothing. So out of the box in library mode there is no per-leaf scan and no joined scan, and the second question gets asked only where the application asks it. That is A-AS9 restated.

In gateway mode it is not yours to remember at all: the proxy checks every string in a call's arguments, plus the joined payload, before the call is allowed through. That claim is the one thing here not drawn from a panel, so it is worth naming what holds it up: test_a_credential_in_an_argument_is_refused, test_a_nested_argument_is_reached, test_a_split_secret_is_refused and test_a_split_canary_is_refused, all in tests/gateway/test_gateway.py.

Mechanism only. check_tool_call, check_outbound, prepare_tool_call and A-AS9 are real, and every outcome shown was run rather than reasoned about: the panel 03 pair, the panel 05 matrix, and both rows of panel 06. Verified against Vörður 2.0.0, commit a0e51be. API names, layer numbering and orderings can change too, not only numbers.
